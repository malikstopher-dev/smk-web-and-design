# smk-web-and-design

SMK Web Design — a high-performance website built with Next.js 15, Tailwind CSS v4, and Framer Motion. Visual replication of helloupdigital.com design language with SMK's real business content.

## Stack

- Next.js 15 (App Router)
- Tailwind CSS v4
- Framer Motion 11
- TypeScript

## Getting Started

```bash
npm install --ignore-scripts --no-audit --no-fund
npm run dev
```

## Build

```bash
npm run build
```
